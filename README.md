# 窗口隐身器 WindowHider

按住准星拖到任意窗口上松开，该窗口就会从**截图、录屏、远程桌面 / 监控软件**的画面里隐身——
全屏截屏里会直接透出窗口后面的桌面或其他窗口，就像这个窗口根本不存在，
而你自己的屏幕上照常显示、照常操作。之后这个程序新开的窗口会自动隐身。

开源，单文件，无依赖。

## 用法

1. 双击 `build.bat`，用 Windows 自带的编译器生成 `WindowHider.exe`（Win7/10/11 都自带，不用装任何东西）
2. 双击运行 `WindowHider.exe`
3. **按住「🎯 按住拖到目标窗口」按钮不放**，把准星拖到想隐身的窗口（比如浏览器）上松开
   - 拖动时目标窗口会有反色边框提示，旁边会显示识别到的程序名
4. 搞定。列表里会显示已隐身的窗口

其他：

- **自动隐身**：拖过一次之后，该程序以后新开的窗口每 2 秒自动补隐身，不用重复拖
- **连本工具一起隐身**：勾选后本工具自己的窗口也隐身
- **最小化到托盘**：点最小化按钮藏到托盘，双击托盘图标回来
- **取消所选保护 / 全部还原**：随时恢复
- **关闭本工具时会自动还原所有窗口**（隐身状态跟着窗口走，工具关了窗口还在的话会先恢复，避免"关不掉的隐身"）

## 原理

Windows 官方 API `SetWindowDisplayAffinity(hwnd, WDA_EXCLUDEFROMCAPTURE)`：
DWM 在合成层直接把该窗口排除在一切软件捕获之外，截图 / 录屏 / 远程画面里就是一块黑色，
本地屏幕完全不受影响。和 DRM 视频播放器防录屏是同一招。

有个坑：这个 API **必须由拥有窗口的进程自己调用**，外部进程调会被系统拒绝。
所以本工具向目标进程注入一小段机器码（约 30 字节），让目标进程自己完成调用，
调完就释放，不留任何文件。注入前会先解析目标进程 user32.dll 的导出表，
算出函数在目标进程里的真实地址，32 位 / 64 位目标都支持。

## 局限

- 只能防**软件**捕获。老师 / 老板站在你身后看、用手机拍照，不受影响
- 目标以管理员身份运行时，本工具也要以管理员身份运行
- UWP 应用（如应用商店版软件）的窗口归 `ApplicationFrameHost.exe` 所有，拖上去保护的是外壳，
  内容可能还是会被截到——这是所有同类工具的通病
- 部分杀软会把"远程线程注入"当可疑行为报毒（这是注入技术的通病，不是病毒）。
  机房没装安全软件的话无视即可
